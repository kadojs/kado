# NOTICE

This file contains a list of dependencies used in the Kado project and the version of Kado that each dependency is using.

## Kado Version
Kado version: 4.5.0

## Libraries Included
- **Application**: Create a new application containing most Kado features.
- **Archive**: Build archives like tar and zip, decompress them.
- **Assert**: Make assertions on input or tests.
- **Asset**: Store, filter, and query static application files.
- **BigInteger**: Use big numbers with JavaScript.
- **ChildProcess**: Child process library adding convenience and functionality to the core child_process functions.
- **Cluster**: Cluster library for constructing and operating process clusters.
- **Command**: Build CLI applications with ease.
- **CommandServer**: Execute CLI applications like a web server.
- **Connect**: Framework for housing external resource connections.
- **ConnectEngine**: Interface for creating an engine to be used with a Connect system.
- **Cron**: Execute functions on a schedule similar to UNIX cron jobs.
- **Database**: Connect system made for Databases.
- **Email**: Connect system made for Email.
- **ETag**: Class for determining ETag header.
- **Event**: Create, track and handle application events with log levels.
- **FileSystem**: Consistent API for use with File System methods.
- **Format**: Commonly used String, Number, and Date format methods.
- **GeoIP**: Lookup IP hosts against a geo-ip database.
- **GetOpt**: Parse command line string input into an object.
- **History**: Track user navigation history throughout a session.
- **HyperText**: Connect system made for HTTP servers.
- **Log**: Logging utilities for application events.
- **LogRelay**: Logging support via UDP.
- **Mapper**: Utility for data mapping.
- **Message**: Create, track and handle messages from various inputs and outputs.
- **Mime**: Class for determining file types.
- **Model**: Create and work with database records.
- **Module**: Kado base module. Used to create new modules.
- **MultiPart**: Handling multipart data.
- **Mustache**: Templating engine.
- **Network**: Networking utilities. IP address utilities.
- **Parser**: Input parsing utilities.
- **PathExp**: Path expression utilities.
- **Permission**: Permission utilities.
- **Profiler**: Profiling utilities. Measure application performance.
- **PromiseMore**: Enhanced promise utilities. Provides Promise Hoisting.
- **Query**: Build queries for databases. An SQL composer.
- **QueryCache**: Cache queries for performance. At the application level.
- **RequestEngine**: Client SDK used to access API instances. Works with almost all RESTful APIs.
- **Router**: Handle routing for web applications.
- **Schema**: Define database schemas. Builds on top of the Query library.
- **Search**: Search factory for use by modules.
- **Session**: Manage user sessions.
- **SessionStoreSQL**: SQL backed sessions from databases.
- **SessionStoreMemory**: In-memory session storage.
- **Stream**: Stream utilities for handling data streams.
- **Util**: Utility functions for various tasks
- **Validator**: Input validation utilities.
- **View**: Implementation of the Mustache templating engine.
